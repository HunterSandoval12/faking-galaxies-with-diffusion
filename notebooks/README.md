# Google Colab tutorials

Tutorials for the project, following the course's tutorial specification
([Colab-tutorial-list.md](https://github.com/pattichis/projects/blob/main/Colab-tutorial-list.md)). Each notebook
runs top to bottom in Google Colab and keeps its data on Google Drive in `MyDrive/galaxy10_tutorial/`. Outside
Colab it uses local folders instead (`galaxy10_tutorial_drive/`, `galaxy10_tutorial_work/`; both git-ignored).

| # | Notebook | Colab runtime | Status |
|---|---|---|---|
| 1 | [`01_Dataset_Tutorial.ipynb`](01_Dataset_Tutorial.ipynb) | CPU | every code cell run locally |
| 2 | [`02_Model_Description_Tutorial.ipynb`](02_Model_Description_Tutorial.ipynb) | GPU (T4) recommended | every code cell run locally |
| 3 | Model Optimization | GPU | planned |
| 4 | [`04_Basic_Testing_Tutorial.ipynb`](04_Basic_Testing_Tutorial.ipynb) | GPU (T4) recommended | every code cell run locally |
| 5 | Basic Fine-tuning | GPU | planned |
| 6 | Full Training | GPU | planned |

**Running a tutorial:** open it in Colab (the *Open in Colab* links in the main README, or *File > Upload notebook*),
then *Runtime > Run all*. Run Tutorial 1 first: it creates the `training` / `validation` / `testing` directories that
the others read. Tutorials 2 and 4 download the trained models with `wget` from the GitHub Release `weights-v1` and
check their SHA-256 checksums; the Stable Diffusion v1.5 base weights come from Hugging Face.

**Editing a tutorial:** each notebook is generated by a script in `_build/` (shared pieces in `_build/nbcommon.py`),
so edit the script and rebuild, e.g. `python notebooks/_build/build_01_dataset_tutorial.py`. The execution-time
tables are filled from a local test run (`--times`). The notebooks are stored without outputs.
